# IPhone 18 PRO MAX

Đây là dự án nền tảng quản lý thanh toán tự động (AutoBank) dành cho Đồ án Lập trình Mobile.

## Cấu trúc dự án (Monorepo)
- `apps/mobile`: Ứng dụng điện thoại Flutter (đọc thông báo, giao diện người dùng).
- `apps/api`: Backend Server NestJS (xử lý giao dịch, đối soát đơn hàng).
- `apps/web`: Giao diện quản lý Web Dashboard (sẽ được phát triển bằng Next.js).
